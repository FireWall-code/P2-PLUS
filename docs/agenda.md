!!! info "D'où viennent ces dates ?"
    De l'emploi du temps Efrei (flux iCal), synchronisé chaque nuit par
    GitHub Actions. Seuls le module, le type de séance, les horaires et les
    supports autorisés sont publiés : ni salles, ni enseignants. Si une date
    change, elle sera corrigée à la synchronisation suivante ; en cas de
    doute, l'emploi du temps officiel fait foi.
