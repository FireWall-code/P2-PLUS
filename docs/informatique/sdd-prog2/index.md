# Structures de données et programmation 2 <small>`TI301P`</small>

Listes chaînées (simples, ht, circulaires, doubles), piles, files, arbres
binaires, ABR et AVL, en C. Le fil rouge du module : **choisir la bonne
structure** pour un problème, **justifier son coût** (complexité), et
l'**implémenter proprement** en C, avec les bons prototypes et tous les cas
limites.

## Infos pratiques

- **Code** : `TI301P` (enseignant : N. Flasque)
- **Évaluation** :

    | DE | CE | Projet |
    |:--:|:--:|:------:|
    | 60 % | 20 % | 20 % |

- **DE** : 1 h 50, sans documents ni calculatrice, réponses sur le sujet (semaine 50).
- **CE** : 1 h (semaine 40). **Projet** : soutenances en semaine 48.
- **Volumes** : CM 6 × 2 h, TD 5 × 2 h, TP 2 h + 3 × 3 h + 1 h, projet 2 × 3 h de suivi + 3 h de soutenance.
- **Outils** : C, CLion pour les TP et le projet ; infos sur Teams et Moodle.
- **IA générative** : conseillée pour réviser (fiches, quiz, explications), déconseillée pour obtenir des corrigés bruts, **interdite en projet** pour générer du code qu'on ne comprend pas. Détails dans [Bonnes pratiques](cours/bonnes-pratiques-c.md#ia-generatives-ce-que-dit-le-module).
- **Ressources officielles** : dans `pdf/ti301/` (local, non publié)
