# :material-dice-multiple: Simulateur d'exercices

Des exercices **générés au hasard** sur les chapitres 1 à 3 (programme du CE) : chaque
clic sur « Nouvel exercice » change les valeurs. Réponds, vérifie, et ouvre l'**indice**
ou la **correction détaillée** si tu bloques. Le score est gardé dans ce navigateur.

<div id="simulateur-proba"></div>

??? info "Les 17 types d'exercices"
    | Chapitre | Exercices |
    |----------|-----------|
    | 1. Espace probabilisé | réunion / intersection / complémentaire, Poincaré à 3 ensembles, effectifs → probabilités, deux dés, « au moins un » sur $n$ essais |
    | 2. Conditionnement | test de dépistage (Bayes), trois machines (probabilités totales), tableau de contingence, urne sans remise, indépendance |
    | 3. Variables discrètes | loi + $E$ + $V$, fonction de répartition, loi conjointe + covariance, binomiale, Poisson, géométrique / binomiale négative, règles de calcul |

!!! tip "Pour réviser le CE"
    1. Fais d'abord une série en mode **Tout**, sans indice.
    2. Repère les types où tu te trompes, puis choisis-les dans le menu **Type**.
    3. Relis la [fiche CE](../fiches/fiche-ce-chapitres-1-3.md) avant de recommencer.
